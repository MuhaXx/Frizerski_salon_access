# Frizerski_salon_access
Frizerski salon želi aplikaciju za upravljanje terminima i klijentima. Frizer želi zakazati termin (klijent, usluga, datum, sat), pregledati raspored za dan i evidentirati plaćanje. Želi vidjeti koji klijenti najčešće dolaze, prihod po vrsti usluge i generisati nedeljni raspored. Aplikacija treba spriječiti dvostruko zakazivanje istog frizera.
